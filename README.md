# Caesar Cipher

## Description
This project is a simple Python implementation of the Caesar Cipher algorithm used for encrypting and decrypting text messages using a shift value. It demonstrates basic cryptography concepts and string manipulation in Python.

## Features
- Encrypt messages
- Decrypt messages
- User-defined shift value
- Supports uppercase and lowercase letters

## Technologies Used
- Python

## How to Run
1. Save the file as `caesar_cipher.py`
2. Open terminal or command prompt
3. Run the program:

```bash
python caesar_cipher.py
```

## Example

Input:
```text
Enter message: HELLO WORLD
Enter shift value: 3
```

Output:
```text
Encrypted Message: KHOOR ZRUOG
Decrypted Message: HELLO WORLD
```
